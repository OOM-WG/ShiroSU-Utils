# [苏柚 / SUU](https://suu.oom-wg.dev)

苏柚 (SUU / ShiroSU Utils) 是 SSU (ShiroSU) 的拓展应用，
对于 Android，支持 普通/adb/root 权限，
并且支持 Windows 平台

苏柚旨在以 普通/adb/root 权限全面地覆盖各类 Android 设备并加以 Windows 的辅助，提升玩机体验。
