# ✨ 什么是苏柚 Nyanya

> [!WARNING]
> 苏柚 Nyanya 的模块独立版已经弃用，不再更新，请使用苏柚软件

## 📚 文档

- [文档地址](https://suu.oom-wg.dev)

苏柚 Nyanya，让杂乱无章的文件世界变得如同精美画卷般整洁可爱喵~ ✨

### 特性

- 完美兼容 `Magisk`、`KernelSU` 或 `APatch`，支持 `Android 5.0` 及以上版本的设备
- 允许自定义魔法配置文件，随心所欲地编排文件，尽显个性

### 安装

1. 下载最新版本的苏柚软件并安装
2. 根据需要编辑配置文件
3. 运行苏柚 Nyanya 功能！
