# [苏柚 / SUU / ShiroSU Utils](https://suu.oom-wg.dev)

> 苏柚 是 [SSU](https://ssu.oom-wg.dev) 的拓展软件，
> 对于 Android，支持 普通/adb/root 权限，
> 并且支持 Windows 平台

苏柚旨在以 _普通_/_adb_/_root_ 权限全面地覆盖各类 Android 设备并加以 Windows 的辅助，提升玩机体验

## 文档

苏柚 的独立文档已弃用，目前已合并至 <https://github.com/OOM-WG/OOM-Website>

## 多语言

多语言相关文件已存放至 [lang 文件夹](lang)，其基于 [FVV](https://github.com/OOM-WG/FVV) 实现并通过 [欢愉多语言框架](https://github.com/OOM-WG/PureJoy-MultiLang) 使用

官方开发成员无力进行多语言维护，仅能维护简中并机翻部分语言，如想为 苏柚 的多语言事业出一份力，可为本仓库发出拉取请求
